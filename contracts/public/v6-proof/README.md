# V6 bounded proof payout

`V6Proof.sil` is the Testnet-10-only verifier for the Observatory lesson. Its
Groth16 circuit proves the small relation

```text
allocation * rate = 42
allocation + rate = 13
1 <= allocation, rate <= 15
```

The worker keeps `allocation` and `rate` private. The verifier receives five
canonical, uncompressed 32-byte BN254 Fr values in this order:

1. `taskScore` (`42`)
2. `rewardUnits` (`13`)
3. `recipientLo128`
4. `recipientHi128`
5. `taskNonce128`

The recipient and nonce values use their first 16 bytes as little-endian
128-bit values and require the remaining 16 bytes to be zero. The contract
also compares the two recipient halves with the full x-only owner key. This
preserves identity without reducing a public key modulo the field. The nonce
binds a proof to one funded task.

The checked-in template is generated by `scripts/v6-proof-artifact.mjs` from
the pinned SilverScript compiler and the local arkworks prover. Its setup seed
is deterministic for development fixtures; it is not a production ceremony.
The lesson demonstrates a bounded arithmetic proof and does not claim general
privacy or useful private computation.
