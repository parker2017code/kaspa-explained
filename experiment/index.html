Messaging (encrypted, on-chain)

Same design as the open-source Kasia messaging app: an encrypted payload riding inside an ordinary TN10 transaction, no server. Uses the official SDK's own CryptoBox (X25519 + XChaCha20Poly1305) instead of Kasia's forked cipher-wasm. A wallet must publish its messaging key once before others can message it.
