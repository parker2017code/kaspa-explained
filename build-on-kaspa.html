Infrastructure note

Some builders need Toccata readiness work

The Toccata node guide is for teams running nodes, wallets, pools, exchanges, explorers, indexers, or custom RPC/protobuf integrations. Ordinary users do not need this checklist.

Nodes

Run Rusty Kaspa v2.0.1 or newer. The node database upgrade is one-way, so operators who might roll back should plan for resync cost.

Fees

Direct RPC submission now uses the upcoming standard-fee floor: 100 sompi * max(compute grams, 2 * transaction bytes). Mempool policy and consensus are separate rule sets.

APIs

New integrations should use storageMass/storage_mass, transaction version 1, input computeBudget, output covenant, and UTXO covenant_id where relevant.

Service providers

Test deposits, withdrawals, mining templates, block submission, indexing, wallet balances, and fee estimation against Testnet-10 and mainnet behavior after activation.

Primary reference: Rusty Kaspa Toccata node setup guide.

Before vProgs

Many ideas start before the full app layer

Some apps need only a payment, a receipt, a vault rule, an escrow path, or an asset rule. Save richer app-state ideas for products that truly need apps to compose with each other.
