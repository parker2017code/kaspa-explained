Infrastructure note

Some builders need Toccata readiness work.

The Toccata node guide matters for anyone running nodes, wallets, pools, exchanges, explorers, indexers, or custom RPC/protobuf integrations. Ordinary users do not need this checklist.

Nodes

Upgrade to Rusty Kaspa v2.0.1 or newer before activation. The node database upgrade is one-way, so operators who might roll back should plan for resync cost.

Fees

Direct RPC submission now uses the upcoming standard-fee floor: 100 sompi * max(compute grams, 2 * transaction bytes). That is mempool policy, not consensus.

APIs

New integrations should use storageMass/storage_mass, transaction version 1, input computeBudget, output covenant, and UTXO covenant_id where relevant.

Service providers

Test deposits, withdrawals, mining templates, block submission, indexing, wallet balances, and fee estimation against Testnet-10 before mainnet activation.

Primary reference: Rusty Kaspa Toccata node setup guide.
