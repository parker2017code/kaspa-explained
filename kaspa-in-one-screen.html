Toccata status

Kaspa in one screen

Kaspa keeps mined money and UTXO ownership, then changes the shape of the ledger. Instead of forcing every honest block into one slow line, it uses a blockDAG and GHOSTDAG so parallel honest work stays in the record and still gets ordered.

Summary

Kaspa is a mined UTXO network betting that Proof-of-Work payments can feel closer to real time. The claim: Bitcoin-style mining can support lower-latency usage without turning into a normal centralized fast database.

Live: PoW mining, UTXO ownership, blockDAG structure, GHOSTDAG ordering, 10 BPS mainnet, wallets, explorers, nodes, mining, transfers, receipts, and accepted-transaction checks. Toccata is live too: it activated at DAA 474,165,565.

Still open: full vProgs, DAGKnight, native DeFi, TangVM/oracle systems, mature Toccata-era apps, and full app-to-app atomic composition. The May 2026 TN10 activation and hardening tests are testnet evidence, not mainnet.

One-line read

Bitcoin-style mining culture, seconds-scale user feel, blockDAG ordering, verifiable receipts today, and future apps that prove their own rules.

Transaction payloads and accepted-transaction checks are live L1 evidence today. Toccata-era app rules, native assets, and vProgs each still need their own receipts, wallet support, explorer support, and product evidence.
