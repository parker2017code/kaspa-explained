# Artificial Analysis — extra evaluations beyond the core leaderboard

Source: https://artificialanalysis.ai/evaluations (evaluations hub, plus each evaluation's own page)
Read date: 20 August 2026
Page date: none of the pages below display an explicit "last updated" date. The evaluations hub's own changelog feed (visible on the AA homepage) shows recent entries dated 12–20 August 2026, including "GLM-5.3 (max) — 18 Aug" and "Qwen3.8 27B — 17 Aug," which sets the likely freshness window, but no date is printed on the evaluation pages themselves.

## Method notes

- Data was read visually from rendered charts on each evaluation's page, not from any API or export.
- These charts render their bar labels/values into the DOM only once scrolled into view (confirmed on AutomationBench-AA and EnterpriseOps-Gym-AA, where the value list was empty until scrolled to). Each table below was captured after scrolling the relevant chart into view and reading the resulting text extraction, cross-checked against the model-count string the page itself prints (e.g. "19 of 62 models").
- Model name strings are copied exactly as each chart printed them, including effort/fallback suffixes. Where a page's own summary sentence names the same model differently than its chart (this happened three times, see notes under Harvey LAB-AA and EnterpriseOps-Gym-AA), both forms are recorded verbatim rather than reconciled.
- "N of M models" means the chart shows N models out of M total models AA has ever tested on that evaluation; only the N shown are reported below because those are the only ones rendered.
- No published confidence interval numbers were visible as text on any of these four evaluations. AA-Briefcase's methodology note states "Elo and 95% confidence interval bounds are clamped at 0" and the bar chart displays visual error-bar caps on top of each bar, but no numeric CI bounds are printed anywhere in the page text — only the bar value itself is a number. This is flagged per-evaluation below.
- Coverage is partial by design: each of these evaluations tests only a subset of AA's full model roster (13–19 models out of 34–62 tracked), so a "Models of interest" model not appearing in a table below was simply not run on that particular evaluation, not a missing/blank cell.

## Areas checked with no additional evaluation found

- **Area 1 (hallucination, factual reliability, calibration, refusal correctness, honesty):** The site's own "Faithfulness" category (4 evaluations) contains only AA-AnalystAgent, AA-LCR, AA-Omniscience, and 𝜏²-Bench Telecom — all four already in the existing dataset. No additional faithfulness/hallucination evaluation was found.
- **Area 3 (long context) beyond what is already held:** The site's "Long Context" category (3 evaluations) contains only Harvey LAB-AA (captured above), AA-LCR (already held), and Terminal-Bench Hard (already held). No dedicated long-context stress-test beyond AA-LCR was found.
- **Area 4 (instruction following) beyond IFBench:** The site's "Instruction Following" category (12 evaluations) is entirely composed of evaluations already held (IFBench, TB-v2.1, TB-Hard, tau2-Telecom, tau3-Banking, MMLU-Pro, Global-MMLU-Lite) plus the four agentic evaluations captured above (AA-Briefcase, GDPval, AutomationBench-AA, Harvey LAB-AA, EnterpriseOps-Gym-AA). MMLU-Pro and Global-MMLU-Lite are tagged "Instruction Following" by AA but their actual content is graduate-level knowledge recall and multilingual knowledge recall respectively, not format/constraint adherence, so they were not pulled in as a separate table — flagging this in case the graduate-knowledge framing is still useful.
- **Area 2 (writing quality, style, translation, summarization) as a standalone prose-quality evaluation:** No such evaluation exists on the site. AA's "Writing" category (3 evaluations: AA-Briefcase, GDPval, Harvey LAB-AA) is entirely agentic document-production benchmarks (spreadsheets, memos, legal filings) graded on task completion and analytical/presentation quality — not a dedicated measure of prose style, translation accuracy, or summarization fidelity in the literary sense.
